# Test Examples Organization

This directory contains test examples organized by component for the PExpr compiler.

## Directory Structure

- `parser/` - Parser edge cases and syntax tests
- `ssa/` - SSA mapper edge cases
- `opt/` - Optimization related tests (includes constant folding, dead code elimination, identity optimization, and common subexpression elimination)
- `typechecker/` - Type checker error cases  
- `uplift/` - UpliftPass variable capture tests
